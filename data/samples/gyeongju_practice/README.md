# 경주 연습용 조사(합성)

`gyeongju_practice_synthetic.gpkg` 는 **합성 자료**다. 실제 유적·조사가 아니다. 황룡사지(국가유산청 좌표) 동남동 약 350 m 에 가상의 조사구역(100×80 m), 시굴 트렌치 4개(2×60 m), 유구·단면선·기준점·유물을 넣었다.
Strata 조사 파일과 같은 7개 레이어·필드(빈 틀은 `hgis/samples/demo_survey/demo.gpkg`), 좌표계 EPSG:5187. 만든 도구: `scripts/make_gyeongju_practice_survey.mjs`.
화면·도면에 쓸 때는 제목에 「합성」이 보이게 한다.
