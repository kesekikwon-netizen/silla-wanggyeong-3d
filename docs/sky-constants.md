# Nishita 하늘 상수 출처

`src/engine/NishitaSky.{h,cpp}` 의 기하·밀도·위상 상수는 Blender 4.2.3 `blender.exe` 의 `.rdata` 에서 읽은 값이다
(파이썬으로 부동소수 배열을 덤프; 파일 오프셋 0x35bf560~):

| 오프셋 | 값 | 의미 |
|---|---|---|
| 0x35bf580 | 2.22e-5 | Mie 산란 계수 (1/m) |
| 0x35bf584 | 6.6667e-5 | 1/15000 — 오존 삼각형 분포의 기울기 |
| 0x35bf588 | 0.0596831 | 3/(16π) — 레일리 위상 |
| 0x35bf58c / 590 / 594 | 1.2672 / 1.52 / 1.5776 | Mie 위상 항: 3(1−g²) / 2g / 1+g² (g = 0.76) |
| 0x35bf5a0 / 5a4 | 1200 / 8000 | Mie / 레일리 스케일 높이 (m) |
| 0x35bf5a8 / 5ac | 25000 / 40000 | 오존 분포 정점 (10–25–40 km) |
| 0x35bf5b0 | 6360000 | 지구 반경 (m) |
| 0x35bf5b4 / 5b8 | 4.04496e13 / 4.12164e13 | 6.36e6² / 6.42e6² (대기 반경 6420 km) |

파장별 레일리 산란·오존 흡수 계수는 Blender 가 스펙트럼 표로 계산하므로 값 그대로는 바이너리에 없다. 여기서는 RGB 근사를 쓴다:
레일리 (5.8, 13.5, 33.1)e-6 /m (Nishita 1993), 오존 흡수 (0.650, 1.881, 0.085)e-6 /m (Hillaire 2020). 따라서 하늘의 색 균형은
Blender 와 같지 않다. 시험은 물리적 성질(위상 적분 1, 일몰 붉어짐, 파란 천정, 지평선 밝음, 밤 어두움)만 확인한다.
